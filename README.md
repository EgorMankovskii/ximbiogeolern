# EduQuest: Научные квесты с Python

EduQuest — образовательная платформа на Django, где ученик решает Python-задачи и одновременно изучает биологию, химию и географию. Проект сделан под тему производственной практики: интерактивная платформа, в которой код становится инструментом исследования виртуальных научных миров.

## Как запустить локально

```powershell
cd C:\Users\egork\OneDrive\Desktop\pyteacher
py manage.py migrate
py manage.py runserver 127.0.0.1:8000
```

После запуска откройте:

```text
http://127.0.0.1:8000/
```

Старая версия с обычными Python-задачами оставлена отдельно:

```text
http://127.0.0.1:8000/classic/
```

## Запуск через Docker и PostgreSQL

В отчете указана архитектура с PostgreSQL и изолированным выполнением кода. Для этого добавлены `Dockerfile`, `docker-compose.yml` и `.env.example`.

```powershell
copy .env.example .env
docker compose up --build
```

Если в окружении задан `POSTGRES_DB`, Django использует PostgreSQL. Если переменных PostgreSQL нет, проект работает на SQLite, чтобы его было проще запускать на учебном компьютере.

Для проверки пользовательского Python-кода можно включить Docker-песочницу:

```powershell
$env:EDUQUEST_SANDBOX="docker"
```

В учебном режиме без этой переменной код выполняется отдельным Python-процессом с ограничениями по AST, времени и запрещенным импортам.

## Соответствие отчету

Проект отражает концепцию из отчета:

- `Био-купол` — мир биологии с задачами про ДНК, популяции, белки, генетику, экосистемы, эволюцию, клетки, микробиом и фенотипы.
- `Квантовая лаборатория` — мир химии с задачами про молярную массу, концентрации, элементы и реактор.
- `Глобальная карта` — мир географии с задачами про климатические данные, координаты, маршруты и JSON.
- Каждый урок идет по сценарию `Теория -> Проблема -> Код/Ответ -> Визуальный результат`.
- За решения начисляются `Research Points`.
- Более сложные уроки открываются только после накопления нужного количества RP.
- На странице прогресса есть древо знаний, достижения, история попыток и графики.
- При ошибках ученик получает подсказку и упрощенный вариант задания.
- Прогресс можно сбросить только после подтверждения.

## Карьера и учебники

В шапке сайта есть вкладка `Карьера`. На ней находится персонаж-химик: его должность растет от ассистента лаборатории до руководителя научной группы. Карьера зависит от общего количества Research Points, а улучшения персонажа открываются по мере прохождения заданий и сохраняются в текущей сессии браузера.

Вкладка `Учебники` содержит короткие справочные материалы по Python, биологии, химии и географии. Эти материалы нужны для подготовки к задачам и повторения теории после ошибок.

## Биологический модуль

В `Био-куполе` сейчас 10 активных уроков. Каждый урок состоит минимум из теоретического шага и Python-практики:

1. Анализ ДНК-последовательностей.
2. Симуляция популяции бактерий.
3. Анализ белковых последовательностей.
4. Сравнение ДНК разных видов.
5. Моделирование наследования генов.
6. Анализ экосистемных данных.
7. Симуляция эволюции.
8. Обработка изображений клеток.
9. Анализ микробиома.
10. Прогнозирование фенотипа.

Из-за учебной песочницы импорты в пользовательском коде запрещены, поэтому задания с `matplotlib` и `OpenCV` проверяют подготовку данных для графиков и анализ матриц изображений. Это оставляет автопроверку безопасной, но сохраняет смысл реальных биологических задач.

## Основные модели

`World` — научный мир: биология, химия или география.

`Lesson` — урок внутри мира. Один урок состоит из нескольких шагов и может иметь порог открытия `min_points_required`.

`Quest` — конкретный шаг урока. Поддерживаются три типа:

- `python` — ученик пишет функцию `solve(...)`, сервер проверяет тесты.
- `quiz` — предметный тест с одним правильным ответом.
- `match` — сопоставление картинок, символов или понятий.

`Progress` — очки и количество решенных задач для текущего ученика.

`Submission` — история попыток: код, результат, количество пройденных тестов и обратная связь.

## Как добавить новый курс или раздел

1. Откройте админку Django.
2. Создайте новый `World`: название, `slug`, предмет, описание, цвета и иконку.
3. Добавьте к нему `Lesson`.
4. Внутри урока создайте несколько `Quest` с разным `step_order`.
5. Для сложных уроков укажите `min_points_required`, чтобы они открывались после прогресса.

Так можно добавить не только новые темы внутри биологии, химии и географии, но и полностью новый курс.

## Как добавить задачу

Для Python-задачи заполните:

- `task_type = python`;
- `starter_code` с функцией `solve(...)`;
- `tests` в JSON-формате;
- `story`, `theory`, `hint`, `easier_text`;
- `reward_points`.

Пример тестов:

```json
[
  {"args": ["ATCG"], "expected": "UAGC"},
  {"args": ["TTA"], "expected": "AAU"}
]
```

Для теста или сопоставления заполните `content`.

Пример `quiz`:

```json
{
  "correct": "rna",
  "options": [
    {"value": "dna", "label": "ДНК хранит информацию"},
    {"value": "rna", "label": "РНК переносит информацию к месту синтеза белка"}
  ]
}
```

Пример `match`:

```json
{
  "pairs": [
    {"picture": "A", "prompt": "Аденин в ДНК", "answer": "U"}
  ],
  "options": [
    {"value": "U", "label": "Урацил"},
    {"value": "G", "label": "Гуанин"}
  ]
}
```
